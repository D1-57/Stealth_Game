Instructions:

Obj model is a "static" model without any animations. 
Fbx has animations, but you still have to configure them to work as much as you want because without your work they won't play. It's kind of obvious, but I'm saying this for beginners. 
Remember to change speed of animation if it's looking too slow or too fast.

If you're using Unity and you want to add animation event to animation, but it says "Read Only", the simplest solution is to click on animation, then on top-bar click Edit and duplicate. Duplicated animation will get rid off "Read Only".
